This is where your preparation needs to evolve beyond Infosys.

Don't start with:

> "Design YouTube."

First learn the building blocks.

### Stage 1

Understand:

- load balancer
- reverse proxy
- API gateway
- cache
- database
- CDN
- object storage
- message queue
- search engine

### Stage 2

Understand:

- horizontal scaling
- vertical scaling
- replication
- sharding
- partitioning
- consistency
- availability
- CAP
- eventual consistency
- leader/follower
- distributed locks

### Stage 3

Design:

- URL shortener
- rate limiter
- notification system
- chat system
- file storage
- news feed
- ride booking
- payment system
- job scheduler

### Stage 4

Understand real tradeoffs.

For example:

> PostgreSQL vs MongoDB?

Not:

> "PostgreSQL is relational."

Instead:

> workload → consistency → schema → query pattern → scaling → operational complexity.

That's the level product companies care about.
