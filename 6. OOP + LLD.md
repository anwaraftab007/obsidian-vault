This becomes particularly important outside service-company interviews.

Learn:

### OOP properly

- SOLID
- encapsulation
- abstraction
- inheritance
- polymorphism
- composition

### Design patterns

Don't memorize 23 patterns.

Understand the useful ones:

- Strategy
- Factory
- Observer
- Builder
- Adapter
- Decorator
- Singleton
- Command
- Template Method

Then practice applying them.

For example:

> "Design a notification system supporting Email, SMS and Push."

You should naturally arrive at something resembling:

```
NotificationService
        |
        ↓
NotificationStrategy
   /      |      \
Email    SMS     Push
```
